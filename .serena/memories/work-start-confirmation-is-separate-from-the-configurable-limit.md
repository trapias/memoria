WorkTracker.start counts active and paused sessions using WorkSessionRepository.count_active; that repository counts globally, without a user filter. The maximum is configurable (default 5, 0 unlimited) and is checked before the fixed consent threshold of three. confirm_parallel must be the boolean True to start beyond three; a pending confirmation returns requires_confirmation and active_sessions before creating sessions, clients or projects. server.py exposes the flag and must retain the session list and instructions in its text response. Memoria Team consumes this base package; its local Docker build copies ../Memoria into its ignored vendor directory, so edits only in vendor are overwritten. Contract tests: tests/test_parallel_sessions.py and tests/test_work_start_tool.py.
